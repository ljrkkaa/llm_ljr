# 3 相似任务

## 🧠 一、最接近“协同围捕（Cooperative Pursuit / Multi-Agent Capture）”的领域

这些domain都涉及多智能体（robots/rovers）协同移动与目标捕获、包围或交互，逻辑上与围捕任务对应：


| Domain                                   | 概念匹配点                           | 对应的围捕类行为                                             |
| ------------------------------------------ | -------------------------------------- | -------------------------------------------------------------- |
| **rovers** 🌍                            | 多个探测机器人在地表移动、拍照、采样 | 类似多个追捕者在区域网格中协作逼近目标位置（移动+感知+通信） |
| **satellite** 🛰️                       | 多个卫星协同拍摄目标区域             | 类似多个智能体同时“瞄准/锁定”目标，需要时间窗口与同步动作  |
| **termes** 🤖                            | 群体机器人协同搭建结构               | 群体协同位置控制，与围捕中的“阵型约束”结构非常类似         |
| **transport / driverlog / logistics** 🚚 | 多机器人（车）协作完成运输、调度任务 | 可抽象为多追捕者的路径协调问题（分布式移动与通信约束）       |
| **goldminer** ⛏️                       | 多个代理协同采集分布式目标点（资源） | 类似多追捕者同时追逐多个目标的并行任务                       |
| **minigrid** 🔲                          | 离散栅格世界中智能体导航、追逐或合作 | 可以直接改造为围捕仿真环境（非常常用）                       |
| **visitall** 🔁                          | 机器人需访问所有区域节点             | 若目标是“捕获逃逸目标”，visitall可视作围捕区域封锁的特例   |
| **spanner** 🔧                           | 机器人前往不同位置使用工具完成操作   | 在逻辑上类似于多个智能体协作在不同区域执行捕获动作           |

**→ 推荐重点参考：`rovers`, `minigrid`, `visitall`**

这三类与“围捕”模型在空间、任务同步与行动协同方面最接近。

## 🧭 二、最接近“协同覆盖（Cooperative Coverage / Area Coverage）”的领域

这些domain关注**区域访问、任务分配与覆盖效率优化** ，与协同覆盖任务直接对应：


| Domain                     | 场景说明                           | 对应覆盖逻辑                  |
| ---------------------------- | ------------------------------------ | ------------------------------- |
| **visitall** 🌐            | 机器人需访问所有区域，确保完整覆盖 | 直接等价于区域覆盖任务        |
| **floortile** 🧱           | 机器人铺设地砖（或清扫地面）       | 经典多机器人区域覆盖问题      |
| **tidybot** 🧺             | 机器人整理房间、收拾物品           | 可映射为覆盖-搜索-操作任务    |
| **hiking / cavediving** 🧗 | 探索未知区域、完成测绘任务         | 区域覆盖 + 路径规划型任务     |
| **rovers** 🌍              | 多机器人采样与观测任务             | 属于科学任务覆盖的范例        |
| **goldminer** ⛏️         | 搜索并覆盖目标资源区域             | 覆盖 + 目标识别任务           |
| **termes** 🤖              | 群体机器人覆盖建造区域             | 协同覆盖与构建联合任务        |
| **grid / minigrid** 🔲     | 栅格环境中覆盖搜索任务             | RL/Planning研究常用覆盖测试域 |

**→ 推荐重点参考：`floortile`, `visitall`, `rovers`, `minigrid`**

这些domain均与多机器人空间覆盖优化问题匹配度高。

## ⚙️ 三、对比总结表


| 类别     | 最相似Domain  | 相似原因                       | 可扩展为围捕/覆盖的方式                  |
| ---------- | --------------- | -------------------------------- | ------------------------------------------ |
| 协同围捕 | **rovers**    | 多机器人在图上移动、通信与感知 | 将采样目标改为“逃逸目标”或“围捕条件” |
| 协同围捕 | **minigrid**  | 离散空间中的多智能体交互       | 改造reward或goal为“包围目标”           |
| 协同围捕 | **satellite** | 多智能体同步对目标执行任务     | 改为“多角度锁定目标”                   |
| 协同覆盖 | **visitall**  | 需访问所有节点（空间覆盖）     | 改造为多机器人联合访问区域               |
| 协同覆盖 | **floortile** | 铺设任务=空间遍历              | 可转化为区域扫描或监控任务               |
| 协同覆盖 | **rovers**    | 探测点分布覆盖                 | 直接对应“任务区域覆盖”                 |
| 协同覆盖 | **termes**    | 群体机器人空间布置             | 对应群体占位/分布式覆盖                  |

## 🔍 四、在 PlanSys2 / PDDL 中可迁移的方式


| 目标任务     | 推荐迁移起点         | 迁移思路                                                                                                                    |
| -------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **协同围捕** | rovers / minigrid    | 保留`(robot_at ?r ?z)` 和 `(connected ?z1 ?z2)`，增加 `(target_at ?t ?z)` 与 `(target_captured ?t)`，再添加 `surround` 动作 |
| **协同覆盖** | visitall / floortile | 保留区域拓扑与访问谓词`(visited ?z)`，多机器人通过 `(cover ?r ?z)` 协作完成覆盖                                             |
