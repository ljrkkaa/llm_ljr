# Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?

https://arxiv.org/abs/2504.13837

可验证奖励的强化学习（RLVR）最近在提升大型语言模型（LLMs）的推理性能方面取得了显著成功，特别是在数学和编程任务上。与传统强化学习帮助智能体探索和学习新策略类似，**RLVR 被认为能够使 LLMs 持续自我改进**，从而获得超出相应基础模型的推理能力。在本研究中，我们通过系统地探究 RLVR 训练的 LLMs 在不同模型家族、强化学习算法以及数学、编程和视觉推理基准测试中的推理能力边界，批判性地考察了 RLVR 的当前状态，并使用在大 k 值下的 pass@k 作为评估指标。令人惊讶的是，我们发现当前的训练设置并没有引发根本性的新推理模式。**虽然 RLVR 训练的模型在小 k（例如 k=1）时优于其基础模型，但当 k 值较大时，基础模型实现了更高的 pass@k 分数。覆盖率和困惑度分析表明，观察到的推理能力源于并受限于基础模型。** 将基础模型视为上限，我们的定量分析表明，六种流行的 RLVR 算法表现相似，且在利用基础模型潜力方面远未达到最优。相比之下，我们发现**蒸馏可以从教师模型引入新的推理模式，真正扩展模型的推理能力**。总体而言，我们的研究结果表明，当前的 RLVR 方法尚未实现利用强化学习来激发 LLMs 真正新颖推理能力的潜力。 这突出了改进强化学习范式的必要性，例如持续扩展和多轮智能体-环境交互释放这一潜力。


研究团队提出了一个新的衡量标准——pass@k，来更准确地评估模型能力边界。通过k次尝试同一题目，只要模型至少一次答对，则视为该题目被解决。使用pass@k 指标后，研究发现经过RLVR训练的模型并未显著扩展其能解决问题的能力边界，甚至在大尝试次数下，其表现不及基座模型。此外，RLVR主要提升的是模型的采样效率，即在同一问题上更容易生成正确答案，但并未真正让模型学会新的推理策略或能力。

实验中还观察到，RLVR过程实际上是在“锐化”基座模型的概率分布，使得某些高概率的回答被进一步放大，而非探索出全新的解题路径。相比之下，使用更高级的微调技术（如基于更强大模型的数据微调）更有可能帮助模型获得新的能力。

研究者强调，本研究并非否定RL的价值，而是指出当前主流的RLVR方法在大元模型中的局限性，尤其是其在极大语言空间中探索能力不足的根本原因。为突破这一瓶颈，研究者提出了**未来可能的方向：包括改进预训练、多层次分解问题、超越Token级别的探索、引入更有效的奖励设计、以及构建能够与外部环境交互的Agent系统，从而实现真正的新能力学习和策略发现。**

关键洞察
🧩 pass@k揭示能力边界真实情况
传统评估只看单次回答正确率，容易低估模型潜力。pass@k通过多次尝试捕捉模型解决问题的最大可能性，更科学地反映模型能力边界，有助于区分性能提升来自于采样效率还是能力扩展。

🔄 RLVR提升的是采样效率，不是能力本身
RLVR通过强化正确答案的概率，减少错误答案出现的概率，使模型在有限尝试中更易找到正确解，但这并不意味着模型学会了新的推理技巧，更多是概率分布的调整。

🧪 强化学习范式的局限来自奖励设计和探索机制
RLVR使用的是稀疏、二元奖励，且决策过程简单，缺乏中间反馈和状态更新，限制了模型通过自我探索发现新策略的能力。

🔧 未来突破方向需多维度改进
包括更丰富多样的训练数据、任务分解策略、**跨越Token级别的高层探索**、改进奖励信号设计及引入能与外界交互的Agent，实现更有效的策略迭代和能力学习。

📉 RLVR训练后部分题目表现反而下降
部分原本能解决的问题因RLVR训练失效，显示RLVR可能在某些方面牺牲了模型的多样性或泛化能力。

🔄 RLVR与传统RL的本质差异
传统RL如AlphaGo能通过自博弈发现全新策略，而RLVR的限制使得其更多是精细调整而非创新，反映了当前技术在语言模型上的适用边界。

本研究为理解和改进大元模型中的强化学习技术提供了重要视角，提醒科研和工程实践者需审慎看待RLVR的作用，并探索更具创新性的强化学习范式。
