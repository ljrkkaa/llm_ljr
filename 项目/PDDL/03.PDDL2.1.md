# 1 引言

PDDL2.1（Fox 和 Long，2003）引入了增加了两个关键的新特性， `durative-actions` 和 `functions` ，它们被称为数值性 fluents ，以便表示资源。在之前的版本中，动作是直接在离散时间中应用的，但在本版本中，动作可以在连续空间中描述和执行，因此它们被描述为时间性或持续性的动作。数值 fluents 可以用于最短路寻址规划，从更广泛的角度来看，硬约束可以保证尽量少地使用特定动作。

# 2 Durative Actions  持续动作

You can actually give actions durations to work in temporal domains.
实际上，你可以为动作设置持续时间，使其在时序域中工作。

Each condition and effect is given the time at which it’s supposed to happen.
每个条件和效果都会被赋予其应该发生的时间。

There are a few types of temporal constraints:
存在几种时序约束类型：

1. (at start (<condition/effect>)) ，表示这必须在动作开始时为真或发生。
2. (at end (<condition/effect>)) ，表示这必须在动作结束时为真或发生。
3. (over all (`<condition>`)) ，表示这必须在动作的整个持续时间内为真。

```
(:durative-action move
:duration (= ?duration 10) ; 动作持续时间为 10 时间单位
:parameters
(?arm - bot            ; ?arm 是一个机器人手臂对象
?from - location      ; ?from 是起始位置对象
?to - location)       ; ?to 是目标位置对象
:condition                ; 持续动作的条件（durative condition），注意这里是 :condition 而非 :precondition
(and
(at start (on ?arm ?from))  ; 动作开始时，手臂在起始位置
(over all (path ?from ?to)) ; 动作执行期间，一直要求 ?from 到 ?to 的路径存在
)
:effect
(and
(at start (not (on ?arm ?from))) ; 动作开始时，手臂不再在起始位置
(at end (on ?arm ?to))          ; 动作结束时，手臂到达目标位置
)
)
```

# 3 Functions  函数

PDDL 中的函数用于表示随动作执行而变化的数值。这些函数在简单的谓词（真/假）不足以应对的更复杂的规划问题中非常有用。函数使规划者能够处理资源、距离或成本等数量。它们非常适合计算温度、速度、能量等变量。

PDDL 中的函数使用:functions 关键字在**领域文件**中定义。它们可以**在动作定义中使用，以动态更新值。**

在下面的示例中， `distance` 函数定义了两个位置之间的距离， `fuel` 函数跟踪车辆的燃料水平。 `drive` 动作根据行驶的距离减少燃料水平。

```
 (define (domain logistics)
  (:requirements :typing :fluents)

  (:types
    package location vehicle - object)

  (:predicates
    (at ?pkg - package ?loc - location)
    (in ?pkg - package ?veh - vehicle)
    (at ?veh - vehicle ?loc - location))

  (:functions
    (distance ?loc1 - location ?loc2 - location) ; 表示两个位置之间的距离，是一个数值函数 R
    (fuel ?veh - vehicle))                       ; 表示某个车辆剩余燃料量，也是数值函数 R

  (:action drive
    :parameters (?veh - vehicle ?loc1 - location ?loc2 - location)
    :precondition (and (at ?veh ?loc1) (> (fuel ?veh) (distance ?loc1 ?loc2)))
    :effect (and (not (at ?veh ?loc1)) (at ?veh ?loc2) (decrease (fuel ?veh) (distance ?loc1 ?loc2)))) ; decrease 内置数值效果

  (:action load
    :parameters (?pkg - package ?loc - location ?veh - vehicle)
    :precondition (and (at ?pkg ?loc) (at ?veh ?loc))
    :effect (and (not (at ?pkg ?loc)) (in ?pkg ?veh)))

  (:action unload
    :parameters (?pkg - package ?loc - location ?veh - vehicle)
    :precondition (and (in ?pkg ?veh) (at ?veh ?loc))
    :effect (and (at ?pkg ?loc) (not (in ?pkg ?veh))))
)
```

## 3.1 PDDL2.1 里的内置数值效果（Numeric Effects）

常见的有：

* **`(assign (f …) value)`**

  把函数直接赋值为某个数值。

  例子：`(assign (fuel car1) 100)`
* **`(increase (f …) value)`**

  在原值基础上加上某个数。

  例子：`(increase (fuel car1) 10)`  → `fuel(car1) = fuel(car1) + 10`
* **`(decrease (f …) value)`**

  在原值基础上减去某个数。

  例子：`(decrease (fuel car1) 5)` → `fuel(car1) = fuel(car1) - 5`
* **`(scale-up (f …) value)`**

  按比例放大。

  例子：`(scale-up (fuel car1) 2)` → `fuel(car1) = fuel(car1) * 2`
* **`(scale-down (f …) value)`**

  按比例缩小。

  例子：`(scale-down (fuel car1) 2)` → `fuel(car1) = fuel(car1) / 2`

# 4 fluents

PDDL 2.1 中的域语法在 1.2 版本的基础上扩展，增加了两个关键的新特性， `durative-actions` 和 `functions` ，它们被称为数值性 fluents。

**数值 fluent 的语法**

* **定义** ：数值 fluent 是和对象元组（tuples of domain objects）相关联的数值，通常通过**domain functions** （领域函数）表示。
* **构造方式** ：数值表达式可以使用**算术运算符** （+、-、*、/ 等）构造，运算对象是这些 primitive numeric expressions。
* **设计理念** ：PDDL 2.1 中采用**前缀形式（prefix syntax）** 的算术运算符和比较运算符，例如`( + a b )`、`( >= x y )`，这样可以简化解析器的处理。

### **数值条件**

* 条件总是 **两两比较 numeric expressions** ，比如

  ```lisp
  (>= (amount jug1) 5)
  ```

  表示 `jug1` 中的量至少为 5。
* 数值可以表示多种角色：资源数量、累积效用（utility）、计数器等。

```
(define (domain jug-pouring)            ; 定义域名称为 jug-pouring
(:requirements :typing :fluents)      ; 使用类型系统和数值 fluent（函数）

(:types jug)                          ; 定义类型 jug

(:functions
(amount ?j - jug)                   ; 函数 amount 表示 jug 当前水量
(capacity ?j - jug)                 ; 函数 capacity 表示 jug 最大容量
)

(:action pour                          ; 定义动作 pour（倒水）
:parameters (?jug1 ?jug2 - jug)      ; 参数 ?jug1、?jug2 都是 jug 类型


:precondition 
  (>=                                 ; 前提条件：jug2 有足够空间接收 jug1 的水
    (- (capacity ?jug2) (amount ?jug2))  ; jug2 剩余容量
    (amount ?jug1)                     ; jug1 当前水量
  )

:effect (and
  (assign (amount ?jug1) 0)          ; 动作效果1：jug1 水量变为 0
  (increase (amount ?jug2) (amount ?jug1)) ; 动作效果2：jug2 水量增加 jug1 的水量
)


)
)
```

# 5 List of Requirements 需求列表

The following is a list of requirements that were added by PDDL2.1 to the language of PDDL.
以下是 PDDL2.1 添加到 PDDL 语言中的要求列表。

* [:fluents]
* [:durative-actions  :持续动作]
* [:durative-inequalities   :持续不等式]
* [:continuous-effects   :连续效果]
* [:negative-preconditions   :负向前提]


一个综合的例子

```
(define (domain rover-domain) ; 定义 domain 名称为 "rover-domain"
(:requirements
:durative-actions         ; 允许定义持续动作 (durative actions)
:fluents                  ; 允许定义数值 fluent (函数)
:duration-inequalities    ; 允许持续时间约束 (duration =, <=, >= ...)
)


(:types 
    rover waypoint            ; 定义类型：探测车(rover)，路径点(waypoint)
)

(:predicates
    ... ; 这里省略了布尔谓词定义，比如 (at ?r ?wp), (can-move ?wp1 ?wp2)
)

(:functions
    (battery-amount ?r - rover)   ; 数值 fluent：探测车 ?r 的电池剩余量
    (sample-amount ?r - rover)    ; 数值 fluent：探测车 ?r 已采样的样本量
    (recharge-rate ?r - rover)    ; 数值 fluent：探测车 ?r 的充电速率
    (battery-capacity)            ; 全局常量：电池最大容量
    (sample-capacity)             ; 全局常量：样本最大存储量
    (distance-travelled)          ; 全局变量：累计行驶距离
)

(:durative-action move            ; 定义持续动作 move (移动)
    :parameters
        (?r - rover                ; 移动的探测车
         ?fromwp - waypoint        ; 出发点
         ?towp - waypoint)         ; 目的地

    :duration
        (= ?duration 5)            ; 持续时间固定为 5 单位时间

    :condition
        (and
            (at start (rover ?rover))                 ; 开始时 ?rover 必须是 rover
            (at start (waypoint ?from-waypoint))      ; 出发点必须是 waypoint
            (at start (waypoint ?to-waypoint))        ; 目的地必须是 waypoint
            (over all (can-move ?from-waypoint ?to-waypoint)) ; 整个持续时间内必须可通行
            (at start (at ?rover ?from-waypoint))     ; 开始时 rover 在出发点
            (at start (> (battery-amount ?rover) 8))  ; 开始时电池电量大于 8
        )

    :effect
        (and
            (decrease (fuel-level ?t) (* 2 #t))        ; 在移动过程中持续消耗燃料 (#t 表示时间流逝)
            (at end (at ?rover ?to-waypoint))          ; 结束时 rover 在目的地
            (at end (been-at ?rover ?to-waypoint))     ; 记录 rover 曾经到过目的地
            (at start (not (at ?rover ?from-waypoint))) ; 开始时 rover 不再在出发点
            (at start (decrease (battery-amount ?rover) 8)) ; 开始时立即减少 8 点电量
            (at end (increase (distance-travelled) 5)) ; 结束时累计行驶距离 +5
        )
)
... ; 其他动作省略


)
```
